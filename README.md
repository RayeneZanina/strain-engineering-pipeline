For this project, I tried to design a pipeline for strain engineering to maximize the production of ethanol (used as an example) using FBA (using cobrapy 10.1186/1752-0509-7-74)
The problem is to find the optimal set of genes to knock out to maximize the target reaction flux. 
Initially, this was the design proposed.

We can represent the cell as a network with nodes representing genes, metabolites and reactions. This would allow us to pass it through a GNN encoder, and pass the GNN embeddings into a flux vector predction MLP.
This theoretically allows us to determine the flux vector much more rapidly than using the optimize method. The embeddings would also represent the observation space of the policy agent and would help it determine the optimal input.
I encountered a few issues with this. The biggest one is that training a neural network to predict the flux vector is extremely difficult as it is extremely non-smooth. I tried adding other correction tools to the prediction but it was not able to 
accurately predict the flux. I think cutting down the genes that can be removed can potentially help so that we don't just kill the cell and get a flux of 0 for the biomass, which the predictor has a lot of trouble with. It could also narrow down the combinations, allowing training the predictor on an actual dataset
instead of using stochastic gradient descent. Another issue is that, PPO which is what I used is more fit for sequential problems, and treating this problem as a sequential one by predicting the next gene to knock out leads to the agent not being able fully explore the different combinations. It also had a lot of trouble learnign when the stop action.
For this kind of problems, it seems that a genetic algorithm is the way to go. It performed slightly better than the PPO with the GNN embeddings. However, for larger cell models, training the GA takes forever because the optimize method takes very long. I was hoping the GNN could make it faster, but it wasn't able to predict the flux accurately enough.
The theoretically best model I had was a genetic algorithm with the GNN embeddings used to reward novelty to allow for the GA to explore more options. It performed as good as the GA by finding what might potentially be the optimal solution for the textbook cell model, but when I tried on other models my kernel crashed, and I kind of didn't really have a lot of motivation to keep going.
